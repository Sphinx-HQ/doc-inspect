# doc-inspect

Open-source document inspection toolkit by [Sphinx](https://sphinxhq.com).

This repository is a **private work in progress**. It will ship a local toolkit that reports what is in a document (metadata, later structural facts) — not whether that document is fraudulent. Production-grade detection lives on [WatchDoc](https://watchdoc.sphinxhq.com).
